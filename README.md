## About

I'm a Computer Engineering student and software developer who enjoys building practical products across the web, mobile, and applied AI. I like taking an idea from a clean interface through to the API, data layer, and real-world details that make it useful.

- 🧱 **Full-stack:** React, Node.js, Express, REST APIs, and PostgreSQL.
- 🧠 **Applied AI:** computer vision, NLP, and on-device model inference.
- 📱 **Mobile:** React Native and native Android development with Kotlin.
- 📚 **Currently growing:** backend architecture, data structures, and system design.
